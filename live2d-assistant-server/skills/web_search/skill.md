# 网络搜索技能

你可以使用 `searx_search` 工具进行网络搜索。

## 使用指南

1. 根据用户的问题，构造合适的搜索关键词（建议使用英文关键词以获得更好的搜索结果）
2. 调用 `searx_search` 工具执行搜索
3. 分析搜索结果，提取与用户问题相关的关键信息
4. 如果搜索结果不够充分，可以调整关键词重新搜索

## 注意事项

- 搜索关键词应简洁精准，避免过于冗长
- 可以多次搜索以获取更全面的信息
- 对搜索结果进行整理归纳后再回复用户，不要直接复制粘贴搜索结果
